Re-run cmake when adding/removing/moving files to ensure the glob patterns pick up the changes, before compiling.

Follow Google C++ Style Guide.
Fields: snake_case_ with trailing underscore. Other variables: snake_case. 
Constants kCamelCase with leading k. Functions: CamelCase with leading uppercase.
Use modern C++23 features where possible.
Use ranges for loops.
Declare variables using auto, const, and using curly braces {} for initialization
whenever possible.
